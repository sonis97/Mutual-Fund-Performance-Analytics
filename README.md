# 📊 Mutual Fund Performance Analytics

An end-to-end Data Analytics project developed during my **Data Analyst Internship at Bluestock Fintech Pvt. Ltd.**

This project analyzes Indian Mutual Fund industry data using **Python, PostgreSQL, SQL, and Power BI** to generate actionable business insights.

---

# 🚀 Project Overview

The objective of this project is to analyze Mutual Fund performance, investor behaviour, SIP trends, portfolio holdings, and benchmark performance using multiple analytical tools.

The project includes:

- Data Cleaning using Python
- Exploratory Data Analysis (EDA)
- SQL Database Design & Analysis
- Interactive Power BI Dashboard
- Business Insight Generation

# ▶️ How to Run

1. Clone this repository.

2. Import the datasets into PostgreSQL.

3. Execute **schema.sql** to create the database schema.

4. Execute **queries.sql** for SQL analysis.

5. Run the Jupyter notebooks.

6. Open the Power BI dashboard.
