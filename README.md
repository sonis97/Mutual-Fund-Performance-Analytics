An end-to-end Data Analytics project developed during my **Data Analyst Internship at Bluestock Fintech Pvt. Ltd.**

## 🚀 Project Overview

This project analyzes mutual fund industry data using **Python, SQL, and Power BI** to generate actionable business insights.

- Data Cleaning using Python
- SQL Analysis
- Exploratory Data Analysis (EDA)
- Interactive Power BI Dashboard
- Risk & Return Analysis
